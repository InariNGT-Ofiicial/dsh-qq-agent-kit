Q00 站内那些 DSH 接入 QQ 的教程，动不动就是十几分钟、二十几分钟。现在，把操作交给 Agent。你要做的交接，只需要三秒钟：把包拖进去，按下回车。来，直接看操作。

Q01 拖进对话框，按下回车。好，交接完成！后面的活儿，让 Agent 接着干。

Q02 先说路线。QQ 官方支持机器人账号，还提供了 DSH 的官方接入插件，名字叫 dsh-qqbot。在插件页安装它，再到设置里的 QQ 机器人，用手机 QQ 扫码绑定，就能接起来。我们除此之外，还支持接入你自己的 QQ 小号。两种账号，都可以在本地部署，也可以放到云端。四条路线就是：官方 bot 本地、官方 bot 云端、QQ 小号本地、QQ 小号云端。选好一条，告诉 Agent，它就按对应路线开工。

Q03 Agent 会检查环境、安装依赖、生成配置，再把模型和 QQ 接起来。轮到扫码的时候，它会叫你拿手机确认。接着发条消息，收到回复，就完成验收。本地可以马上试起来；搬到云端，你关掉电脑，她也能继续聊天。

Q04 接上之后，打开 DSH 的 QQ 中控，就能直接调整群聊开关、消息落盘、回复模式和冷却时间。现在还加上了人格文件编辑：写好工作约定和人物设定，预览一下，再保存到选定的工作区。平时怎么聊，什么时候接话，都能安排明白。

Q05 群消息也能自动落盘。消息进来，先按群和日期记好，再决定要不要回复。这样，你可以让她安静地听，也可以让她参与聊天。想回顾大家聊了什么，直接打开记录就能看。

Q06 想让她安静一点，就选仅艾特回复：叫到她，她再接话。想让她一起聊，就切到自主参与：发来新消息，她就可以接上。再配好冷却时间和每小时回复上限，聊天节奏就稳了。需要休息的时候，把总开关关掉就好。

Q07 交接包里，安装脚本、检查工具、测试和恢复步骤都备齐了。本地接入、云端收发，还有群聊落盘和两种回复模式，我们都实际跑过。Agent 可以照着这些步骤部署、检查、排查问题，你只要和它确认账号与使用方式就行。

Q08 交接包交给 Agent，你负责决定怎么用她。欢迎加入我们的 Agent 账号社会实验群：小肥鱼幼儿园一班。群号就在画面上。来一起搭建、一起观察，看看 Agent 走进真实群聊以后，能玩出些什么！
