# DSH QQ 中控

面向 DSH 0.2.1-rc.2 的 Cordis bundle。安装 tgz 后在 DSH 插件设置中调整原生开关，不要求独立网页。Agent 配置私密 connectionFile，支持本地目录或已有SSH连接；包内不含服务器地址、密钥或QQ登录态。

群聊总开关不关闭QQ客户端、不停止原私聊。落盘独立于回复模式：off可以只记录，mention仅@回复，autonomous接收新消息后无需@参与，但遵守冷却和每小时上限。不主动定时找人、不跨群、不重放旧消息、模型不可执行工具。

群聊worker需另外部署并使用本包固定脚本。插件管理配置、worker执行消息策略；未运行worker时改变开关不会凭空启动QQ。默认全部关闭且群名单为空。完整步骤与验收见外层交接包。
